# PULSE

Учебный адаптивный лендинг фитнес-центра, выполненный по десктопному макету курса. Промежуточный и мобильный layout были спроектированы и реализованы самостоятельно, поскольку отсутствовали в исходном макете.

## Реализовано

- адаптивная навигация и бургер-меню;
- продуктовый слайдер;
- табы в секции About;
- аккордеон с адресами фитнес-центров;
- модалка с формой, scroll lock и focus trap;
- видеолайтбокс;
- состояния hover и focus;
- управление интерактивными компонентами с клавиатуры;
- базовая семантика и ARIA-атрибуты.

## Стек

- HTML5;
- CSS3, BEM, Flexbox, Grid, custom properties, `clamp()` и media queries;
- Vanilla JavaScript: ES Modules, DOM API и event delegation;
- Swiper 12;
- FsLightbox.

Сторонние библиотеки и шрифты подключены локально. Сборщик и фреймворки не используются.

## Адаптивность и доступность

Основные проверочные ширины — 1440, 768 и 375 px. Минимальная поддерживаемая ширина — 375 px.

Интерактивные элементы проверены с клавиатуры. Для модалки реализованы перенос и удержание фокуса с последующим возвратом на триггер. Аккордеон синхронизирует визуальное состояние с `aria-expanded`. Страница также была вручную проверена с NVDA.

## Запуск

Проект необходимо открывать через локальный HTTP-сервер, например Live Server. При запуске через `file://` ES-модули могут не загрузиться.

## Использование AI

AI использовался как наставник и инструмент для отладки. Часть решений была предложена AI, после чего код разбирался, адаптировался и проверялся в проекте.

## Статус

Основная версия завершена. После финального коммита проект замораживается без дальнейшей полировки.

Проект остаётся frontend-прототипом: форма не подключена к серверу, а часть ссылок используется только для демонстрации интерфейса.
