# PULSE

## Definition of Done

Проект считается завершённым, когда:

- свёрстаны все запланированные секции;
- реализована основная интерактивность:
  - бургер-меню;
  - слайдер;
  - табы;
  - видеолайтбокс;
  - аккордеон;
  - модальное окно;
- нет критических визуальных ошибок на ширинах 1440, 768 и 375 px;
- нет очевидных ошибок в семантике и доступности;
- README отражает фактическое состояние проекта;
- выполнен финальный коммит и проект заморожен.

## Working principles

- Сначала уменьшать сложность и трение.
- Новые интерактивные компоненты сначала собирать в песочнице.
- Делить большую задачу на маленькие законченные этапы.
- В каждый момент иметь один ясный следующий шаг.
- Не смешивать в одной сессии структуру, логику, доступность и финальный дизайн без необходимости.
- Сначала понимать минимальную механику, затем переносить её в основной проект.
- Не копировать готовое решение, пока не понятен принцип его работы.
- Фиксировать выполненный прогресс и обновлять следующий шаг.
