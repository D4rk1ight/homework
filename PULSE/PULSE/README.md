# PULSE Fitness

Учебный адаптивный лендинг фитнес-клуба. Проект используется не только для вёрстки макета, но и для практики реальной разработки: декомпозиции задач, самостоятельного поиска решений, отладки и добавления интерактивности через минимально необходимый JavaScript.

Проект считается завершённым, когда:

- [ ] Собраны все секции, входящие в текущий объём проекта.

- [ ] Нет очевидных ошибок в HTML-семантике и базовой доступности.

## Задача на следующую сессию

1. В песочнице найти кнопку внутри ранее открытого пункта.
2. При закрытии этого пункта установить его кнопке `aria-expanded="false"`.
3. Проверить все состояния:
   - изначально ничего не открыто;
   - пункт открывается мышью;
   - пункт открывается через `Enter` и `Space`;
   - повторное нажатие закрывает текущий пункт;
   - открытие другого пункта закрывает предыдущий;
   - клик по содержимому не закрывает аккордеон;
   - значения `aria-expanded` соответствуют визуальному состоянию.
4. Перенести готовую механику из песочницы в основной PULSE.
5. После переноса заполнить контент пунктов Locations.

Следующая сессия считается результативной, если завершена песочница и её рабочая логика перенесена в основной проект. Заполнение всего контента в ту же сессию не обязательно.

## Ограничения текущего объёма

В текущую версию не входят:

- бесконечная полировка декоративных деталей;
- pixel-perfect проверка на всех возможных ширинах;
- полная переработка уже работающих секций;
- дополнительная клавиатурная навигация стрелками, `Home` и `End`, если базовая доступность через кнопки уже работает;
- усложнение JavaScript ради демонстрации дополнительных технологий.
