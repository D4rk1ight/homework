### Что закрепилось

- DOM-элемент и boolean — разные типы данных.
- `querySelector()` возвращает элемент или `null`.
- `closest()` ищет ближайшего подходящего предка.
- `classList.toggle()` изменяет класс и возвращает итоговое состояние.
- `classList.contains()` возвращает boolean.
- DOM-элементы через `===` сравниваются по идентичности.
- Псевдоэлемент принадлежит DOM-элементу, а не CSS-классу.
- Несколько CSS-селекторов могут дополнять стили одного и того же псевдоэлемента.

# Working principles

## Делать сложное легче

- сначала уменьшать трение;
- новые сложные компоненты сначала изолировать в песочнице;
- не пытаться решить всю задачу сразу;
- превращать большую задачу в маленькие законченные действия.

## Один ясный следующий шаг

В каждый момент должен существовать один ответ на вопрос:

> Что конкретно я делаю сейчас?

Не «сделать модалку», а, например:

> перенести overlay и window в PULSE.

## Учиться через практику

- сначала пробовать самому;
- при нехватке знаний проверять, действительно ли не хватает знаний, а не практики;
- использовать уже знакомые DOM-методы в новых задачах;
- спрашивать «что возвращает эта операция?» и «почему это работает?»;
- читать чужой код после того, как базовая механика уже знакома.

## Не смешивать сессии без необходимости

Отдельными задачами считать:

- механику;
- визуальный дизайн;
- accessibility;
- чтение библиотеки;
- перенос;
- React / TypeScript.

## Критерий хорошей сессии

Сессия хорошая не тогда, когда сделано всё.

Сессия хорошая, когда:

- было несколько маленьких законченных шагов;
- стало понятнее, чем было до начала;
- есть видимый результат;
- следующий шаг на завтра уже записан.
